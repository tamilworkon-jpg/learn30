<Section id="top-facts" type="topFacts" title="Top facts" minutes={15}>

1. AI ⊃ machine learning ⊃ deep learning ⊃ generative AI; agentic AI uses generative models to plan and act with tools (Day 1).
2. Underfitting means high bias and poor results everywhere; overfitting means high variance — great on training data, poor on new data (Day 2).
3. Real-time inference is for low latency, batch for large offline datasets, asynchronous for big payloads or long processing and serverless for intermittent traffic (Day 2).
4. Classification predicts a category, regression predicts a number and clustering groups unlabelled data (Day 3).
5. Transformers use self-attention to process sequences in parallel and power LLMs (Day 4).
6. Comprehend analyses text, Transcribe does speech → text, Polly does text → speech, Rekognition analyses images and video and Textract extracts forms and tables (Day 5).
7. Precision avoids false positives, recall avoids false negatives and F1 balances both (Day 6).
8. A managed API such as Amazon Bedrock means no servers and pay per use; self-hosting on a SageMaker AI endpoint gives more control but you run the infrastructure (Day 6).
9. A token is a chunk of text — roughly three-quarters of an English word — and context windows and prices are counted in tokens (Day 8).
10. Chunking splits long documents into smaller passages before embedding, and overlap stops ideas being cut in half (Day 8).
11. An embedding is a vector that captures meaning; similar meanings sit close together and are found with similarity search such as cosine similarity (Day 8).
12. Foundation models are pre-trained on broad data and adapt to many tasks; multimodal models handle more than one data type (Day 8).
13. Diffusion models generate images by starting from random noise and removing it step by step, guided by a prompt (Day 8).
14. The FM lifecycle runs data selection → model selection → pre-training → fine-tuning → evaluation → deployment → feedback, and most organisations start from an existing FM instead of pre-training (Day 9).
15. On-demand pricing charges input and output tokens separately, and output tokens usually cost more (Day 9).
16. Context engineering decides what enters the context window — instructions, retrieved knowledge, history, tool results and memory — within the token budget (Day 9).
17. An agent is an FM in a loop: it reasons about a goal, calls tools, observes results and repeats until the task is done (Day 10).
18. The model chooses a tool and its arguments, but the application or agent runtime actually runs the tool (Day 10).
19. MCP is an open protocol in which hosts run MCP clients that connect to MCP servers exposing tools, resources and prompts (Day 10).
20. Strands Agents is an open-source SDK and Bedrock AgentCore runs agents securely at scale (Runtime, Gateway, Memory, Identity, Policy, Observability) — the recommended path for new agents; Bedrock Agents (managed) is closed to new customers since July 2026, though existing agents keep working (Day 10).
21. Hallucinations are confident but false outputs, and nondeterminism means the same prompt can give different answers (Day 11).
22. GenAI business value is measured with business metrics such as ROI, conversion rate, ARPU, customer lifetime value and cost per interaction (Day 11).
23. Amazon Bedrock gives fully managed, serverless API access to foundation models from Amazon (Nova) and other providers (Day 12).
24. SageMaker JumpStart is a hub of pre-trained models you deploy and fine-tune in your own account (Day 12).
25. Amazon Quick serves business users, Kiro is a spec-driven agentic IDE for developers and AWS Transform handles migration and modernisation (Day 12).
26. Your prompts and data are not used to train Bedrock base models (Day 12).
27. Batch inference processes asynchronous jobs from Amazon S3 at around half the on-demand price for supported models (Day 13).
28. Provisioned throughput buys reserved model units billed hourly for guaranteed capacity and is usually needed to serve custom models (Day 13).
29. Prompt caching reuses a repeated prompt prefix to cut input cost and latency, and the smallest model that meets the need is the biggest price lever (Day 13).
30. AWS Budgets alerts on spend, while AWS Cost Explorer analyses and forecasts it (Day 13).

<Section id="traps" type="traps" title="Exam traps" minutes={5}>

- **"Use an embedding model to write the summary"** — embedding models output vectors, not text. They help find relevant chunks; a text-generation FM writes the answer.
- **"Pick the biggest context window and send every document"** — this raises cost and latency and can lower quality. Select relevant content (RAG), compress history or cache a repeated prefix instead.
- **"The LLM calls the API directly"** — the model only returns which tool to call and with what arguments; the application, Lambda function or agent runtime runs it.
- **"Model accuracy proves business value"** — accuracy, ROUGE and latency describe the model. Business value needs ROI, conversion, ARPU, CLV, efficiency or CSAT.
- **"SageMaker AI for least operational overhead"** — serverless FM access through an API is Amazon Bedrock. SageMaker AI is for full control; JumpStart is for deploying pre-trained open models in your account.
- **"Provisioned throughput is always cheaper"** — it is billed per hour even when idle. For variable or modest traffic on-demand is cheaper; for offline jobs use batch.
- **"GenAI for tax calculations"** — when the answer must be exact, deterministic and auditable, use ordinary code or rules, not a generative model.
- **"Amazon Q is the business assistant"** — guide v1.2 names Amazon Quick for business users and Kiro for developers; treat Amazon Q options with suspicion.
