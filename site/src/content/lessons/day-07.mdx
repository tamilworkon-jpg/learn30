<Section id="top-facts" type="topFacts" title="Top facts" minutes={15}>

1. AIF-C01 v1.2 has 65 questions (50 scored, 15 unscored) in 90 minutes, a pass mark of 700 on a 100–1000 scale and five domains weighted 20/24/28/14/14 (Day 1).
2. AI ⊃ machine learning ⊃ deep learning ⊃ generative AI, and agentic AI uses generative models to plan and take actions with tools (Day 1).
3. Machine learning learns patterns from data instead of following hand-written rules (Day 1).
4. On AWS, pre-built AI services solve common tasks, Amazon SageMaker AI builds custom models and Amazon Bedrock serves foundation models for generative and agentic AI (Day 1).
5. An algorithm learns from training data to produce a model; inference is using that model on new data (Day 2).
6. Hyperparameters are set before training (for example learning rate or epochs); parameters such as weights are learned during training (Day 2).
7. The training set teaches the model, the validation set tunes it and the test set gives an honest final score on unseen data (Day 2).
8. Underfitting means high bias and poor results everywhere; overfitting means high variance — great on training data, poor on new data (Day 2).
9. Real-time inference serves low-latency requests, batch scores large offline datasets, asynchronous handles big payloads or long processing via a queue and serverless suits intermittent traffic (Day 2).
10. Labelled data has the answer attached and enables supervised learning; SageMaker Ground Truth helps produce labels (Day 3).
11. Classification predicts a category and regression predicts a number — logistic regression is a classifier (Day 3).
12. Clustering, dimensionality reduction (PCA) and anomaly detection are unsupervised: they find structure without labels (Day 3).
13. Reinforcement learning learns by trial, error and reward, while foundation models are pre-trained with self-supervised learning (Day 3).
14. A neural network learns by a forward pass, a loss function, backpropagation and gradient descent repeated over many epochs (Day 4).
15. CNNs suit images, RNNs process sequences step by step and transformers use self-attention in parallel to power LLMs (Day 4).
16. Transfer learning reuses a pre-trained model and fine-tunes it on a small labelled dataset, saving data, time and cost (Day 4).
17. Avoid AI when the answer must be exact and rule-based, when errors are unacceptable without review or when a simple rule is cheaper (Day 5).
18. Comprehend finds sentiment, entities and PII in text; Transcribe turns speech into text; Polly turns text into speech; Translate converts languages; Lex builds chatbots with intents and slots (Day 5).
19. Rekognition analyses images and video, Textract extracts text, forms and tables from documents and Personalize produces recommendations (Day 5).
20. Traditional ML suits structured data, strict explainability, low latency and low cost; foundation models suit unstructured data and content generation (Day 5).
21. The ML pipeline runs business goal → data collection → preparation and feature engineering → training and tuning → evaluation → deployment → monitoring → retraining (Day 6).
22. SageMaker AI features map to stages: Data Wrangler prepares data, Feature Store shares features, Pipelines automates, Model Registry versions and approves, Model Monitor detects drift (Day 6).
23. Precision measures how many alerts are right, recall measures how many real cases are caught, F1 balances both and RMSE or MAE measure regression error (Day 6).
24. Business metrics such as cost per user, ROI and customer feedback decide whether a model is worth running (Day 6).

<Section id="traps" type="traps" title="Exam traps" minutes={5}>

- **"Deep learning is a separate field from ML"** — no: deep learning is a subset of machine learning, and generative AI is a subset of deep learning.
- **"Bias always means unfairness"** — read the context: with training versus test scores or model complexity, bias means systematic error (underfitting); with groups of people, it means unfair outcomes.
- **"Logistic regression is regression"** — it predicts a category, so it is classification. Decide by the output, not the algorithm's name.
- **"Deep learning is always the best choice"** — for a small structured table where explainability, low cost or regulation matter, traditional ML usually wins.
- **"Transcribe reads text aloud"** — Transcribe is speech → text, Polly is text → speech, Translate is language → language, Comprehend understands text and Textract extracts text and structure from documents.
- **"99% accuracy means a great fraud model"** — on rare positives accuracy hides a useless model. Missing a case is costly → recall; false alarms are costly → precision; both → F1.
- **"Batch inference for a chatbot"** — interactive, low-latency use cases need real-time inference; batch is for large offline jobs.
- **"Use Amazon Forecast, Amazon Fraud Detector or Amazon Kendra"** — none of these is in guide v1.2; prefer SageMaker AI for custom forecasting or fraud models and Bedrock Knowledge Bases for document search.
- **"AWS DeepLens or Amazon Q is the answer"** — older courses show them, but DeepLens is discontinued and v1.2 names Amazon Quick and Kiro instead of Amazon Q.
